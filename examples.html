交互实验室 ​

用同一块内容比较三种入口。默认启用网页全屏，你可以取消勾选「仅网页全屏」以尝试浏览器原生模式。

组件 ​

v-model 驱动状态，适合页面内的独立全屏区域。

查看组件代码与说明 →

指令 ​

点击按钮触发；目标通过选择器指定，状态通过回调更新。

查看指令代码与说明 →

API ​

直接指定 DOM，等待请求完成，手动处理错误。

查看 API 代码与说明 →

示例版本

页面内的交互示例使用当前仓库的 Vue 3 适配器。Vue 2 的实际运行通过独立 playground 和兼容测试验证；两者的模型事件差异见版本说明。
