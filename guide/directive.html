指令 ​

点击绑定的元素即可切换目标区域的全屏状态，无需维护模型状态。

触发器与全屏目标

指令绑定的元素是点击触发器，target 指定的才是全屏目标。 绑定元素不会自动成为全屏目标；不指定目标时，默认控制 document.body。

演练场 ​

演练场

正在加载示例…

vue
<script setup>
import { ref } from 'vue'
import { vFullscreen } from 'vue-fullscreen'

const active = ref(false)
const options = {
  target: '#panel',
  pageOnly: false,
  teleport: true,
  callback: (isFullscreen) => {
    active.value = isFullscreen
  },
}

function report(error) {
  active.value = false
  console.error(error)
}
</script>

<template>
  <div>
    <button
      :disabled="active"
      v-fullscreen="options"
      @fullscreen-error="report($event.detail)"
    >
      进入全屏
    </button>
    <section id="panel">
      <!-- 需要全屏的内容 -->
      <button
        v-if="active"
        v-fullscreen="options"
        @fullscreen-error="report($event.detail)"
      >
        退出全屏
      </button>
    </section>
  </div>
</template>

普通 setup() 或 Options API 中，在组件的 directives 选项里用 fullscreen: vFullscreen 局部注册。

绑定值与修饰符 ​

vue
<!-- 不传参数：控制 document.body -->
<button v-fullscreen>整个页面全屏</button>

<!-- 按钮是触发器，#report 区域才是全屏目标 -->
<button v-fullscreen="'#report'">报表全屏</button>
<section id="report">
  报表内容
  <button v-fullscreen="'#report'">退出全屏</button>
</section>

<!-- 对象：目标与配置 -->
<button v-fullscreen="{ target: '#report', pageOnly: true, teleport: true }">
  网页全屏
</button>

target 还支持 HTML 元素、Vue ref、组件实例（使用 $el）和 getter，进入全屏时解析当前目标。直接传入的字符串按 CSS 选择器处理，id 应写成 '#report'。

无法解析目标时触发 fullscreen-error。直接传入 null 与省略 target 相同。

修饰符 ​

.pageOnly 和 .teleport 对应同名配置。对象中的显式选项优先于修饰符。例如 .pageOnly="{ pageOnly: false }" 最终使用原生模式。

对象还支持 fullscreenClass 与 callback(isFullscreen)。在全屏目标内部也绑定同一指令，即可作为退出按钮；开启会话的指令卸载时自动清理。

配置项 ​

ts
interface DirectiveOptions extends ApiOptions {
  target?: FullscreenTarget
}
选项类型默认值说明
targetFullscreenTargetdocument.body目标；直接传入的字符串按 CSS 选择器解析
pageOnlybooleanfalse网页全屏
teleportbooleanfalse移动到 body；目标是 body 时自动关闭
fullscreenClassstring'fullscreen'激活时添加，退出时恢复
callback(isFullscreen: boolean) => void无状态变化回调

回调 ​

通过 callback 接收实际的全屏状态变化。

js
const options = {
  callback(isFullscreen) {
    console.log(isFullscreen)
  },
}

错误事件 ​

指令通过原生冒泡事件 fullscreen-error 报告失败，错误对象在 event.detail。

js
button.addEventListener('fullscreen-error', (event) => {
  console.error(event.detail)
})

如果按钮在全屏目标外面，原生全屏时可能看不到它。请在目标内部提供退出按钮，或让用户使用 Esc。
