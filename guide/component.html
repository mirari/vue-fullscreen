组件 ​

把内容放进组件，用 v-model 控制。用户按 Esc 退出时，绑定的状态会自动变回 false。

旧版本升级提醒

5.x 改用按需导入，不再提供全局插件注册。旧项目请参阅迁移示例。

正在加载示例…

vue
<script setup>
import { ref } from 'vue'
import { Fullscreen } from 'vue-fullscreen'

const active = ref(false)

function report(error) {
  active.value = false
  console.error(error)
}
</script>

<template>
  <div>
    <button :disabled="active" @click="active = true">进入全屏</button>
    <Fullscreen
      v-model="active"
      :page-only="false"
      :teleport="true"
      @error="report"
    >
      <!-- 需要全屏的内容 -->
      <button v-if="active" @click="active = false">退出全屏</button>
    </Fullscreen>
  </div>
</template>

属性 ​

属性类型默认值说明
modelValuebooleanfalsev-model 绑定值
pageOnlybooleanfalse仅填满网页；不支持原生 API 时自动启用
teleportbooleanfalse全屏期间将元素移动到 body
fullscreenClassstring'fullscreen'激活期间的 class
exitOnClickWrapperbooleantrue点击容器背景退出；点击子元素不会触发
fullscreenbooleanfalse已废弃的模型属性，保留兼容

事件 ​

事件参数时机
changeboolean全屏状态改变
update:modelValueboolean同步 v-model
update:fullscreenboolean同步旧模型属性
error错误对象模型变化或容器点击触发的操作失败

方法与状态 ​

vue
<script setup>
import { ref } from 'vue'
import { Fullscreen } from 'vue-fullscreen'

const panel = ref()
const error = ref('')
async function enter() {
  try {
    await panel.value.request()
  } catch (reason) {
    error.value = reason.message
  }
}
</script>

<template>
  <button @click="enter">进入全屏</button>
  <Fullscreen ref="panel" page-only>内容</Fullscreen>
  <p v-if="error" role="alert">{{ error }}</p>
</template>
成员类型 / 签名作用
request(): Promise<void>请求全屏
exit(): Promise<void>退出全屏
toggle(force?: boolean): Promise<void>切换或指定状态
isFullscreenboolean当前全屏状态
isEnabledboolean原生全屏是否可用

旧版本迁移 ​

js
// 旧写法
import VueFullscreen from 'vue-fullscreen'
app.use(VueFullscreen)

// 新写法
import { Fullscreen } from 'vue-fullscreen'
vue
<!-- 旧写法 -->
<fullscreen :fullscreen="active" @update:fullscreen="active = $event" />

<!-- 新写法 -->
<Fullscreen v-model="active" />
