API ​

通过 useFullscreen() 获取响应式状态和操作方法，适合从多个按钮、快捷键或业务逻辑中控制同一全屏目标。

演练场 ​

演练场

正在加载示例…

vue
<script setup>
import { ref } from 'vue'
import { useFullscreen } from 'vue-fullscreen'

const target = ref()
const { isFullscreen, enter, exit } = useFullscreen(target, {
  pageOnly: false,
  teleport: true,
})

function report(error) {
  console.error(error)
}
</script>

<template>
  <div>
    <button :disabled="isFullscreen" @click="enter().catch(report)">
      进入全屏
    </button>
    <section ref="target">
      <button v-if="isFullscreen" @click="exit().catch(report)">
        退出全屏
      </button>
      <!-- 需要全屏的内容 -->
    </section>
  </div>
</template>

目标 ​

目标支持 HTML 元素、Vue 模板 ref、组件实例（使用 $el）、id 字符串、CSS 选择器以及 getter。字符串先按 id 查找（允许带 #），未找到时再按 CSS 选择器解析；两者都能匹配时，id 优先。每次进入时解析当前目标，无法解析或 ref 尚未挂载会拒绝 Promise。省略目标或直接传入 null 时控制 document.body。

js
useFullscreen(document.getElementById('panel')) // HTML 元素
useFullscreen(target) // Vue 模板 ref
useFullscreen('panel') // id
useFullscreen('#panel') // 带 # 的 id
useFullscreen('.panel') // CSS 选择器

各次调用的全屏状态相互独立。需要从多个位置控制同一目标时，共享同一次 useFullscreen() 调用返回的状态和方法。组件卸载时自动退出，恢复被移动的元素并移除监听器。原生全屏请求应直接由点击或按键触发，不要先等待网络请求。

组件外使用 ​

useFullscreen() 也可以在组件外调用。每次调用独立管理会话；组件外没有卸载生命周期，结束时需要自行调用 exit()。

ts
import { useFullscreen } from 'vue-fullscreen'

const { enter, exit } = useFullscreen('#panel', {
  pageOnly: true,
  teleport: true,
})
await enter()
await exit()

参数 ​

ts
useFullscreen(target?: UseFullscreenTarget, options?: UseFullscreenOptions): UseFullscreenReturn

返回值 ​

属性 ​

属性类型说明
isFullscreenReadonly<Ref<boolean>>随实际退出同步的响应式状态
isSupportedComputedRef<boolean>原生全屏可用性；不影响网页全屏

方法 ​

方法签名说明
enter(): Promise<void>进入全屏
exit(): Promise<void>退出全屏
toggle(): Promise<void>切换全屏

配置项 ​

选项类型默认值
pageOnlyboolean、ref 或 getterfalse
teleportboolean、ref 或 getterfalse
fullscreenClassstring、ref 或 getter'fullscreen'

选项在每次进入时读取。原生能力不支持时自动使用网页全屏，请求失败时恢复 DOM 并拒绝 Promise。

旧版本迁移 ​

js
// 旧写法
import { api } from 'vue-fullscreen'
api.request(target, { callback: onChange })

// 新写法
import { useFullscreen } from 'vue-fullscreen'
const { isFullscreen, enter, exit } = useFullscreen(target)
