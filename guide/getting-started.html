快速上手 ​

在使用的位置按需导入组件、指令或 API。

1. 安装 ​

sh
npm install vue-fullscreen

接口版本和安装渠道见兼容性说明。

2. 基本使用方式 ​

以下三种方式任选其一。示例使用 <script setup>，要求 Vue 3.2+。

组件 ​

通过 v-model 控制内容区域的全屏状态。详细用法见组件。

vue
<script setup>
import { ref } from 'vue'
import { Fullscreen } from 'vue-fullscreen'

const active = ref(false)
</script>

<template>
  <Fullscreen v-model="active">
    <button @click="active = !active">切换全屏</button>
  </Fullscreen>
</template>

指令 ​

点击按钮切换整个页面的全屏状态。详细用法见指令。

vue
<script setup>
import { vFullscreen } from 'vue-fullscreen'
</script>

<template>
  <button v-fullscreen>切换页面全屏</button>
</template>

API ​

通过 useFullscreen() 获取响应式状态和操作方法。详细用法见 API。

vue
<script setup>
import { useFullscreen } from 'vue-fullscreen'

const { toggle } = useFullscreen()
</script>

<template>
  <button @click="toggle">切换页面全屏</button>
</template>

其他导入方式 ​

CommonJS ​

js
const { Fullscreen, vFullscreen, useFullscreen } = require('vue-fullscreen')

浏览器全局 ​

通过 UNPKG 加载 Vue 3 的最新版本和本包的 latest 渠道，先加载 Vue：

html
<div id="app">
  <fullscreen v-model="active">
    <button @click="active = !active">
      {{ active ? '退出全屏' : '进入全屏' }}
    </button>
  </fullscreen>
</div>

<script src="https://unpkg.com/vue@3/dist/vue.global.js"></script>
<script src="https://unpkg.com/vue-fullscreen@latest"></script>
<script>
  Vue.createApp({
    components: { fullscreen: VueFullscreen.Fullscreen },
    data: () => ({ active: false }),
  }).mount('#app')
</script>

TypeScript 类型声明由 exports 根据 ESM 或 CommonJS 自动选择。

全屏选项 ​

pageOnly ​

pageOnly 决定使用原生全屏还是网页全屏，默认值为 false。

  • false：请求浏览器原生全屏，隐藏地址栏、标签栏等浏览器界面，适合看图、视频等沉浸式内容。
  • true：在当前网页内铺满视口，保留浏览器界面，适合编辑器、仪表盘等需要随时切换标签页的场景。
原生全屏网页全屏
配置pageOnly: false（默认）pageOnly: true
显示范围浏览器提供的全屏区域当前网页视口
浏览器工具栏由浏览器隐藏保留
用户手势需要点击、按键等用户操作不需要
退出浏览器 Esc、退出按钮、exit()Esc、退出按钮、exit()

浏览器支持、自动降级和 iframe 权限见兼容性。

teleport ​

teleport 决定是否将全屏目标临时移到 document.body，默认值为 false，退出全屏时恢复原位置。

原生全屏只显示全屏元素及其后代。如果内容中的对话框、下拉菜单等实际挂载在 body 下，开启 teleport 会让 body 成为原生全屏元素，使这些浮层也能显示。网页全屏下，移动目标还可以避免祖先元素的裁剪、定位或层叠上下文影响。
