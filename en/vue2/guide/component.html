Vue 2 component ​

Wrap content in the component, then change the v-model value to enter or exit fullscreen. It binds the value prop and input event. Exiting fullscreen automatically sets the bound value to false.

vue
<script>
import Vue from 'vue'
import VueFullscreen from 'vue-fullscreen'

Vue.use(VueFullscreen)

export default {
  data: () => ({ isFullscreen: false }),
  methods: {
    report(error) {
      this.isFullscreen = false
      console.error(error)
    },
  },
}
</script>

<template>
  <div>
    <button :disabled="isFullscreen" @click="isFullscreen = true">
      Enter fullscreen
    </button>
    <fullscreen
      v-model="isFullscreen"
      :page-only="false"
      :teleport="true"
      @error="report"
    >
      <button v-if="isFullscreen" @click="isFullscreen = false">
        Exit fullscreen
      </button>
      <!-- Your fullscreen content -->
    </fullscreen>
  </div>
</template>

Component props ​

PropTypeDefaultPurpose
valuebooleanfalsev-model value
pageOnlybooleanfalseFill the page; automatic fallback if native fullscreen is unavailable
teleportbooleanfalseMove the element to the body while active
fullscreenClassstring'fullscreen'Class applied while active
exitOnClickWrapperbooleantrueExit on wrapper background clicks, not child clicks

Instance properties ​

Read these through the component ref.

PropertyTypePurpose
isFullscreenbooleanCurrent fullscreen state
isSupportedbooleanNative API support

Events ​

EventArgumentPurpose
changebooleanFullscreen state changed
inputbooleanSynchronize v-model
errorError objectA model change or wrapper click triggered a failed operation

Methods ​

Set ref="panel" on the component to call its methods:

js
async enterPanel() {
  try { await this.$refs.panel.enter() }
  catch (error) { this.error = error.message }
}
MethodSignaturePurpose
enter(): Promise<void>Enter fullscreen
exit(): Promise<void>Exit fullscreen
toggle(force?: boolean): Promise<void>Toggle or force a state

Migrating older versions ​

Use enter() instead of request(), and isSupported instead of isEnabled. The old names remain compatibility aliases.

The legacy fullscreen prop and update:fullscreen event remain available for compatibility. Use v-model in new code.

vue
<!-- Before -->
<fullscreen
  :fullscreen="isFullscreen"
  @update:fullscreen="isFullscreen = $event"
/>

<!-- Now -->
<fullscreen v-model="isFullscreen" />
js
// Before
this.$refs.panel.request()
this.$refs.panel.getState()
this.$refs.panel.support

// Now
this.$refs.panel.enter()
this.$refs.panel.isFullscreen
this.$refs.panel.isSupported
