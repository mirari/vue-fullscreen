vue-fullscreenFullscreen for Vue

Control native or page-only fullscreen using a component, directive or API.

Quick start
Playground

Component

Control fullscreen with v-model. The bound value updates when the user exits fullscreen.

Directive

Toggle fullscreen when a button is clicked, with a target element and optional settings.

API

Get reactive state and control fullscreen with useFullscreen, enter, exit and toggle.
