Vue 2 指令 ​

点击绑定的元素即可切换目标区域的全屏状态，无需维护模型状态。

触发器与全屏目标

指令绑定的元素是点击触发器，target 指定的才是全屏目标。 不指定目标时，默认控制 document.body。

演练场 ​

编辑此示例

正在加载示例…

vue
<script>
import Vue from 'vue'
import VueFullscreen from 'vue-fullscreen'

Vue.use(VueFullscreen)

export default {
  data() {
    return {
      isFullscreen: false,
      options: {
        target: '#panel',
        pageOnly: false,
        teleport: true,
        callback: (value) => {
          this.isFullscreen = value
        },
      },
    }
  },
  methods: {
    report(error) {
      this.isFullscreen = false
      console.error(error)
    },
  },
}
</script>

<template>
  <div>
    <button
      :disabled="isFullscreen"
      v-fullscreen="options"
      @fullscreen-error="report($event.detail)"
    >
      进入全屏
    </button>
    <section id="panel">
      <button
        v-if="isFullscreen"
        v-fullscreen="options"
        @fullscreen-error="report($event.detail)"
      >
        退出全屏
      </button>
      <!-- 需要全屏的内容 -->
    </section>
  </div>
</template>

绑定值 ​

vue
<!-- 不传参数：控制 document.body -->
<button v-fullscreen>整个页面全屏</button>

<!-- 按钮是触发器，#report 区域才是全屏目标 -->
<button v-fullscreen="'#report'">报表全屏</button>
<section id="report">
  报表内容
  <button v-fullscreen="'#report'">退出全屏</button>
</section>

<!-- 对象：目标与配置 -->
<button v-fullscreen="{ target: '#report', pageOnly: true, teleport: true }">
  网页全屏
</button>

对象还支持 fullscreenClass 与 callback(isFullscreen)。指令使用共享 API，所以 fullscreen.exit() 可以退出由指令开启的全屏。

修饰符 ​

.pageOnly 和 .teleport 对应同名配置。对象中的显式选项优先于修饰符。例如 .pageOnly="{ pageOnly: false }" 最终使用原生模式。

目标 ​

通过绑定对象的 target 指定全屏目标，支持以下类型：

目标类型示例
HTML 元素{ target: document.getElementById('panel') }
Vue ref 对象{ target: panelRef }
组件实例{ target: this.$refs.panel }，使用其 $el
id 字符串{ target: 'panel' } 或 { target: '#panel' }
CSS 选择器{ target: '.panel' }
getter{ target: () => this.$refs.panel }

字符串先按 id 查找（允许带 #），未找到时再按 CSS 选择器解析；两者都能匹配时，id 优先。每次进入全屏时解析当前目标。

省略目标或直接传入 null 时使用 document.body；选择器未匹配、ref 尚未挂载等无法解析目标的情况会触发 fullscreen-error。

简写 v-fullscreen="'panel'"、v-fullscreen="'#panel'" 和 v-fullscreen="'.panel'" 也遵循相同的解析规则。

配置项 ​

ts
interface DirectiveOptions extends ApiOptions {
  target?: FullscreenTarget
}
选项类型默认值说明
targetFullscreenTargetdocument.body支持类型见目标
pageOnlybooleanfalse网页全屏
teleportbooleanfalse移动到 body；目标是 body 时自动关闭
fullscreenClassstring'fullscreen'激活时添加，退出时恢复
callback(isFullscreen: boolean) => void无状态变化回调

回调 ​

通过 callback 接收实际的全屏状态变化。

js
const options = {
  callback(isFullscreen) {
    console.log(isFullscreen)
  },
}

错误事件 ​

指令通过原生冒泡事件 fullscreen-error 报告失败，错误对象在 event.detail。

js
button.addEventListener('fullscreen-error', (event) => {
  console.error(event.detail)
})

如果按钮在全屏目标外面，原生全屏时可能看不到它。请在目标内部提供退出按钮，或让用户使用 Esc。
