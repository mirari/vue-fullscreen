Vue 2 API ​

适合从多个按钮、快捷键或业务逻辑中控制同一全屏目标。插件将 fullscreen 单例注册为实例属性 $fullscreen，可以直接调用。

演练场 ​

编辑此示例

正在加载示例…

vue
<script>
import { fullscreen } from 'vue-fullscreen'

export default {
  data: () => ({ isFullscreen: false }),
  methods: {
    enter() {
      fullscreen
        .enter(this.$refs.target, {
          pageOnly: false,
          teleport: true,
          callback: (isFullscreen) => {
            this.isFullscreen = isFullscreen
          },
        })
        .catch(console.error)
    },
    exit() {
      fullscreen.exit().catch(console.error)
    },
  },
  beforeDestroy() {
    if (fullscreen.element === this.$refs.target)
      void fullscreen.exit().catch(console.error)
  },
}
</script>

<template>
  <div>
    <button :disabled="isFullscreen" @click="enter">进入全屏</button>
    <section ref="target">
      <button v-if="isFullscreen" @click="exit">退出全屏</button>
      <!-- 需要全屏的内容 -->
    </section>
  </div>
</template>

原生模式下，应在路由离开守卫中等待 fullscreen.exit()，再移除目标。

目标 ​

通过 fullscreen.enter() 的第一个参数指定全屏目标，支持以下类型：

目标类型示例
HTML 元素fullscreen.enter(document.getElementById('panel'))
Vue ref 对象fullscreen.enter(panelRef)
组件实例fullscreen.enter(this.$refs.panel)，使用其 $el
id 字符串fullscreen.enter('panel') 或 fullscreen.enter('#panel')
CSS 选择器fullscreen.enter('.panel')
getterfullscreen.enter(() => this.$refs.panel)

字符串先按 id 查找（允许带 #），未找到时再按 CSS 选择器解析；两者都能匹配时，id 优先。每次进入全屏时解析当前目标。

省略目标或直接传入 null 时使用 document.body；选择器未匹配、ref 尚未挂载等无法解析目标的情况会拒绝 Promise。

切换与强制状态 ​

ts
await fullscreen.toggle(element, { pageOnly: true }) // 根据当前状态切换
await fullscreen.toggle(element, { pageOnly: true }, true) // 强制进入
await fullscreen.toggle(element, undefined, false) // 强制退出
await fullscreen.exit() // 已退出时不执行操作

enter() 默认控制 document.body。已处于全屏时再次 enter() 不会切换目标；先退出，再请求新目标。

方法 ​

ts
fullscreen.enter(target?: FullscreenTarget, options?: ApiOptions): Promise<void>
fullscreen.toggle(target?: FullscreenTarget, options?: ApiOptions, force?: boolean): Promise<void>
fullscreen.exit(): Promise<void>

实例属性 ​

属性类型说明
isFullscreenboolean当前控制器状态
isSupportedboolean原生全屏支持情况
elementElement | null目标元素，退出后为 null
options会话配置当前配置；不要在会话期间修改

这些是普通属性，不是 Vue 的响应式引用。想让页面随 Esc 等操作更新，请使用 callback 同步 Vue 状态，或使用组件的 v-model。

配置项 ​

选项类型默认值说明
pageOnlybooleanfalse网页全屏
teleportbooleanfalse移动到 body；目标是 body 时自动关闭
fullscreenClassstring'fullscreen'激活时添加，退出时恢复
callback(isFullscreen: boolean) => void无状态变化回调

回调 ​

js
fullscreen.enter(target, {
  callback(value) {
    // 同步页面状态
    isFullscreen = value
  },
})

旧版本迁移 ​

使用 enter() 替代 request()，使用 isSupported 替代 isEnabled。旧名称作为兼容入口保留。
