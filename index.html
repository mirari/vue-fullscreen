vue-fullscreenVue 全屏组件

通过组件、指令或 API 控制原生全屏和网页全屏。

快速上手
演练场

组件

使用 v-model 控制全屏状态。用户退出全屏时，绑定值会同步更新。

指令

为按钮添加点击切换全屏的行为，可指定目标元素和全屏选项。

API

通过 useFullscreen 获取响应式状态，使用 enter、exit 和 toggle 控制全屏。
