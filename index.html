vue-fullscreen给内容，多一点空间。

为 Vue 2 和 Vue 3 添加全屏体验。用组件连接状态，用指令增强按钮，或用 API 精确控制。

三种入口，同一套能力

组件适合 v-model，指令适合点击触发，API 适合业务流程。无需更换全屏实现。

原生全屏，也能填满网页

按场景选择隐藏浏览器工具栏，或仅填满当前页面；不支持原生全屏时自动降级。

Vue 2 / Vue 3 一起维护

共用浏览器核心，分别适配生命周期和模型事件，继续支持现有使用方式。
