# Vue 2 Playground

修改代码后点击「运行」，在预览中测试 `pageOnly`、`teleport` 和弹窗效果。原生全屏**只能由**点击、触摸或按键等用户操作触发。

预览中的 `pageOnly` 只填满预览区域。支持单个 `App.vue` 的 Options API、JavaScript 与 CSS；内置 Vue 2.7 和当前项目版本的 `vue-fullscreen`。
