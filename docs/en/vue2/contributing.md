# Feedback

Report issues in [GitHub Issues](https://github.com/mirari/vue-fullscreen/issues).

Include the Vue and vue-fullscreen versions, browser and device, and code that reproduces the problem. State whether you use `pageOnly` or `teleport` and include any error messages.

For usage questions, see the [FAQ](/en/vue2/guide/faq) and [API reference](/en/vue2/reference/api).
